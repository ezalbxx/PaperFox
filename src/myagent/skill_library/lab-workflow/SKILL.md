# 实验工作流（本项目原创）

入口：智慧树 `/lab`，或 `myagent lab`。本技能由 `lab_project.py`、`lab_pipeline.py`、`lab_tools.py`、`lab_report.py` 执行。

- 材料：只读导入，PDF按实际页码提取；旧报告不作为新实验测量。
- 规划：只安排实验本体，报告格式、交付清单和JSON归档由控制器负责，不重复派任务。
- 执行：`lab_files`读写实验文件，`lab_python`运行已保存的Python领域程序。没有命令字符串、shell、cmd或任意argv参数。长作业固定Python解释器，暂停后按回执接续。
- 证据：运行回执、源代码与产物哈希自动保存。成功执行和存在的产物是完成条件，口头宣告不算完成。
- 写作：独立上下文，只使用原始指标文件、代码和运行回执；图文采用稳定段落ID，不把内部编号堆到正文。
- 评阅：独立只读角色，最多两轮定向修订，仍有意见就交付草稿和意见。不要补造检查或让同一错误无限重试。
- 批注：只替换用户选择的段落或评阅明确指出的关联块，不重新执行实验；保留报告版本。
- 持久化：项目JSON、每次运行的原始JSONL和导出JSON。恢复跳过已完成任务，不自动重放未知副作用。

PyMuPDF和ReportLab是底层格式库；本技能、调度逻辑和业务协议由项目自行编写，未移植开源Agent工具。

当前范围：文字PDF、Python领域库、本机环境。DSH/MCP/远程模型部署等实验适配器尚未实现时应明确阻断，不模拟完成。
