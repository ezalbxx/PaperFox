回答深度独立于工作模式：自动识别小问与深入研究，也可手动选择。深入模式会启用模型推理，耗时与用量会增加。

PDF阅读、报告生成、写代码与Python实验使用我们自己编写的技能，不提供直接shell/cmd入口。前台实验最多30秒；长任务由技能启动后台作业。暂停会中断前台Python并停止后续操作，已启动的后台作业仍保留。

PDF流程：引用指导书，描述要完成的实验与报告要求；纸狐通过技能读PDF、写实验代码、运行并依据真实结果生成PDF。扫描件暂需OCR，不会臆造原文。

左侧直接续接历史对话，“导出”可保存含工具轨迹的对话JSON，用于课程留痕。运行中导出仅包含当时已保存的记录。

关闭页面不会停止本机服务里的任务；关闭服务或重启电脑后，打开历史并点击“继续目标”。文件操作以当前工作目录为默认位置。
